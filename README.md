# 🏧 ATM Simulation

A simple and interactive **ATM Simulation System** developed in **Python** using **Object-Oriented Programming (OOP)** principles. This project simulates the core functionalities of a real ATM through a command-line interface, making it an excellent project for learning Python classes, objects, methods, and user authentication.

---

## 🚀 Features

- 👤 Create a new account
- 🔐 Secure login with PIN
- 💰 Check account balance
- ➕ Deposit money
- ➖ Withdraw money
- 🧾 View transaction history
- 🖨️ Generate transaction receipts
- ❌ Delete account
- 🚪 Logout and Exit
- ⏰ Date & time recorded for transactions

---

## 🛠️ Built With

- Python 3
- Object-Oriented Programming (OOP)
- `datetime` module
- Command Line Interface (CLI)
